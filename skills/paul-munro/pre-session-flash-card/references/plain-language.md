# Plain language

## The test

Read the line out loud. If a smart person outside your field would stop and ask what a word means, replace the word. The card gets read at speed, mid-conversation, while you are also listening to someone else. Every clause it takes to parse is a clause you are missing from the client.

## Banned words

pooled · denominator · exact-boundary · classifier · leading indicator · verdict metric · custody · provenance · instrument · arm · cohort · construct · artifact (as a word for a document) · stakeholder · capability · operationalize · pre-registered · counterfactual · directional read

Also banned: any phrase that only makes sense if you already read the underlying analysis.

## Translations that set the pattern

| Analyst phrasing | Card phrasing |
|---|---|
| the classifier | the rule that sorts accounts into two types |
| data custody | who keeps the files |
| the middle band of the distribution | the 30 accounts in the middle |
| binding constraint has moved downstream | the broken step moved, so look again |
| run once at nomination freeze, then frozen | run it once when the account list freezes, then leave it alone |
| exact-boundary form | say which side of the line it falls on |

## Numbers

Numbers stay, always. They are the decisions. Write them as numerals, including at the start of a sentence. If a number needs context to mean anything, give the context in plain words on the same line. Keep that context out of footnotes.

## Sentence shape

- One idea per sentence.
- Bold the lead-in phrase, so the eye can find the item without reading the paragraph.
- Say the decision before the reasoning.
- Put anything you mean to say out loud in quotes.
- Define a thing by stating what it is, in one positive sentence.

## When plain and short pull against each other

Comprehension comes before brevity. A hard chain of reasoning gets spelled out in plain words. The order of operations: the format is fixed, plain language always, and length as short as the chain allows.
