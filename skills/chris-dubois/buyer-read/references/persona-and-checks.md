# Persona and the nine checks

Open this for the persona (step 3) and the checks (step 5).

## The persona block

Write a short character block before reading the copy. Pull every element from the documents and cite where each came from.

- **Name, age and role.** Invent only the name. The rest comes from the documents.
- **The business, sized.** Locations, staff, tenure, revenue band.
- **What they name first when asked what's hard**, in their own words if the documents have them.
- **Their failure history with vendors like this one.** The burn scars make them skeptical.
- **How they arrived at this page.** A referral, a search, a conference badge scan. Different arrivals need different things above the fold.
- **The physical moment.** Where they are, on what device, with how long.

If the documents don't cover an element, write "not in the documents" and leave it blank. Never fill it with a guess. Blanks lower BR1, which is the honest result of a thin document. A range stays a range.

Specificity is what makes the findings concrete. "A busy owner" finds nothing. "Fifty-one, runs a nine-truck HVAC company his father started, checking his phone in the van between calls" finds real problems.

## The nine checks

Run each one deliberately. If a check needs a source you don't have, mark it "not run" and name the missing source.

1. **The three cold questions.** What am I being sold, what does it cost, and show me one you've built. A page that can't answer all three has an absence problem however well it's written.
2. **Domain reality.** Does every scene survive this buyer's operating reality? Check hours, staffing, seasonality, and how they get customers. This catches errors no writer notices and every buyer does.
3. **Absence audit.** What would this buyer go looking for that isn't here? Price, work samples, geography, who they'd work with, what happens if it fails.
4. **Proof inventory.** List the proof the client already has and check it against the page. Proof sitting unused in a transcript from three weeks ago is a research failure.
5. **Peer vocabulary.** Would this buyer say this word to a peer, unprompted? Apply it hardest to the main CTA and anything above the fold.
6. **Falsifiability.** Does the page make a claim about the reader's business that they can disprove in thirty seconds? If it's wrong about them, the page breaks.
7. **Self-assessment honesty.** If the page asks the buyer questions (a quiz, a scorecard), can they answer them? A diagnostic that asks what only a vendor can measure returns a guess.
8. **Incumbent adjacency.** Who is the buyer comparing this to, and what does that competitor lead with? If the incumbent leads with a credential this page can't answer, that's a finding even on a strong page.
9. **The named-first problem.** Does the page acknowledge what this buyer names first? Run this only if the documents say what comes first; list order is not evidence. Surfacing the gap is different from recommending it go on the page. A problem the client can't solve usually belongs in the sales conversation. Report the gap and say which you think it is.
