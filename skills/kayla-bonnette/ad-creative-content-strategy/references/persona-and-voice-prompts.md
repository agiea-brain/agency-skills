# Step 3: Audience persona research

Four parts, run in order in the same chat. The outputs live in the chat as structured analysis and feed straight into Step 4. No separate doc is needed for this step.

## Part A: Review scrape

```
Go to {brand} website and scrape all available reviews directly from the product pages, up to a
maximum of 5,000. If fewer are available, work with what's there and note the total number of
reviews used in your analysis. Export the results as a CSV.
```

## Part B: Persona extraction

Run straight after Part A in the same chat.

```
From this CSV of reviews, please do the following:
1. Extract 3 or more core personas. Give each a name that reflects their main trigger or problem,
   an age range, and a one-line descriptor. For each persona, write a 2-3 sentence emotional
   narrative covering what they feared, what they wanted, and what finally made them act.
2. Pull 2-3 verbatim quotes per persona that signal their core pain point or desire. These are
   potential ad hooks.
3. Rank the personas by how frequently they appear in the reviews. Create a second ranking by which
   personas use the most emotional language.
4. End with a demographic summary of 50-75 words identifying the dominant audience segment, shared
   emotional triggers, and the single biggest unmet desire across all reviews. Write this as if you
   are briefing a media buyer before a campaign launch.
```

## Part C: Audience comparison

Confirm the brand immersion deck has been shared in this chat before running.

```
Compare who {brand}'s actual audience is, based on their customer reviews, with who they appear to
think their audience is, based on their ad library and brand immersion deck responses. Please
include:
1. Where there is crossover: what did they get right
2. What is missing: which key customer personas from the reviews are not being reflected in their
   ad content or creative strategy
```

## Part D: Tone of voice and key messages

```
Based on everything in this conversation (the brand immersion deck, ad library analysis, competitor
analysis, and audience personas) define the following for {brand}:
1. Tone of voice: 3-4 defining characteristics with a brief description of each and a do/don't
   example for each
2. Language guidelines: 3 do/don't pairs covering specific language, phrases, or claims to use or
   avoid, sourced directly from the brand immersion deck. Format these separately from the TOV
   characteristics; they will appear as their own section in the final HTML report.
3. What to avoid: any tones, phrases, or approaches that would feel off-brand or that competitors
   are already owning
4. Key messages: 5-6 core messages that should run through all content, each mapped to the audience
   persona it speaks to most directly
```
