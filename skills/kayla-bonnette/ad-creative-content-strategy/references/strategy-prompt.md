# Step 4: Content strategy

Synthesises all prior research into a full content strategy for direct-response ad creative: content pillars, hook examples, funnel mapping and a testing framework.

## Before running the prompt

- Confirm Steps 1, 2 and 3 are complete and all outputs are in this chat.
- Have the channels, budget and production capacity confirmed and ready to fill in.

## Prompt

```
Using all of the research and analysis from this conversation (the ad library analysis, competitor
analysis, audience personas, and brand immersion deck responses) please outline a content strategy
for direct-response ad creative for {channels}. The end report should be an HTML file with proper
visual styling, charts, and layout. It should match the brand look and feel. Please include:
- Snapshot of the ad creative analysis
- Snapshot of the competitor analysis
- Snapshot of the audience personas
- Snapshot of TOV and key messages, including language guidelines as a standalone section
- Content pillars with key messages mapped to audience personas
- Hook examples for each content pillar. Write 3 hooks per pillar using varied hook types. Include
  at least one from each of the following across your pillars: solution/problem-first,
  curiosity/pattern interrupt, contrarian, before/after, comment format, fear-based, or
  future-self/phone ringing. Do not default to solution-based hooks only.
- Funnel stage outline with pillars mapped across four stages: Unaware, Solution Aware, Brand Aware,
  and Conversion
- Testing framework appropriate to the budget and production capacity
```

## Output

One HTML report saved to the client folder. This is the primary client deliverable.
